## Demo breve
1. Abrir https://polinexo.onrender.com/polinexo antes del pitch para permitir el arranque del servicio gratuito.
2. Elegir próximas materias, seleccionar un plan válido de 9–15 créditos y revisarlo. Mostrar que incumplir requisitos no permite confirmarlo.
3. Mejorar mi promedio: mostrar una recomendación y su explicación basada en el perfil ficticio, sin prometer notas.
4. Saber si me voy a atrasar: Plan completo y Si pospongo una materia. Seleccionar Estructuras de datos; comparar Análisis de algoritmos antes/después. Posponer Discretas también afecta su correquisito Estructuras y consecuencias posteriores.
5. Abrir la burbuja Nexi y hacer una pregunta breve. Mostrar el nombre del modelo y las herramientas consultadas. Esto acredita una llamada real; una animación o una prueba unitaria no la reemplaza. Si hay error de cuota o del proveedor, mostrarlo honestamente y usar evidencia previamente registrada como evidencia anterior, no llamada actual.
6. Mostrar código server/http.mjs (GoogleGenAI / generateContent) y server/agent.mjs (herramientas y validación). README identifica gemma-4-26b-a4b-it y LICENSE contiene MIT.

## Evidencia por categoría
Gemma: modelo Gemma 4 servido por Gemini API, SDK oficial; la conversación y revisión de planes son funciones centrales. Requiere clave válida en Environment de Render, nunca en diapositivas ni Git.
Open Source AI: código original funcional en GitHub público con MIT; modelo abierto central. No se redistribuyen pesos. No se presenta una Agent Skill como entregable: ese requisito del estándar solo corresponde si postulan una skill. La originalidad y elegibilidad final las decide el jurado.
