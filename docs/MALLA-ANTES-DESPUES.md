# Comparación visual del avance
Dos vistas: Plan completo (materias y horario ingresado por el estudiante) y Si pospongo una materia (malla comparativa por niveles). Por defecto se muestra la ruta afectada; se puede ampliar con las materias sin cambios. Antes supone aprobar el plan; después retira la materia y propaga incompatibilidades de correquisitos antes de proyectar las siguientes asignaturas. Verde: cumpliría requisitos; rojo: pierde acceso; ámbar: dependencia posterior o materia pospuesta. Las condiciones sin verificar siguen pendientes. No predice fechas de graduación ni inventa horarios oficiales. Cambiar de vista conserva el horario introducido mientras la vista permanezca montada.
